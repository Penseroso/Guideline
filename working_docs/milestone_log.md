# Milestone Log

Replaces per-decision `DEC-`/`REV-` entries (archived at `history/decisions.md`, `history/review_log.md`) as the active decision record. One entry per roadmap milestone (`working_docs/product_roadmap.md` §3), written once when the milestone's direction is set or the milestone completes — not once per individual choice. Keep entries short: what changed, why, what it affects. Full historical rationale for anything pre-2026-08-18 lives in `history/decisions.md`/`history/review_log.md`; don't restate it here, link to it.
